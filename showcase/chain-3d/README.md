# The chain in 3D

`index.html`: a standalone demo (three.js, nothing to install) of the 3D view of The Seed's admin
console, with sample data. Open the file in a browser, or turn on GitHub Pages for this repository.

`ChainView3D.tsx`: the console's React component, which shows the real chain live (the last 40
blocks, their transactions, the game's contracts and the players' wallets).
