# La chaîne en 3D

`index.html` : démo autonome (three.js, aucune installation) de la vue 3D de la console
d'administration de The Seed, avec des données d'exemple. Ouvre le fichier dans un navigateur, ou
active GitHub Pages sur ce dépôt.

`ChainView3D.tsx` : le composant React de la console, qui affiche la vraie chaîne en direct (les
40 derniers blocs, leurs transactions, les contrats du jeu et les wallets des joueurs).
